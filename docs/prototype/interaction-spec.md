## 1. 如何查看原型

1. 下载附件 `whiteboard-prototype.html`，双击用 Chrome / Edge / Safari 打开（无需服务器、无外部依赖）。
2. 画面底部有「评审演示」面板，可一键切换 6 个关键状态（空态 / 输入中 / 出图中 / 错误态 / 多图形共存 / 选中编辑）。
3. 也可以直接走真实链路：按 `F`（或点左侧工具栏新增的 **ƒ** 按钮）→ 输入方程 → 回车 → 画布出图。

## 2. 核心交互流程

```
① 按 F / 点 ƒ 工具
      │  右侧属性面板切换为「方程编辑器」
      ▼
② 输入方程（键盘输入 / 符号按钮 π √ ² ³ |x| / 13 个模板一键填充）
      │  输入即校验：✓已识别（绿色）/ ⚠错误原因（红色）
      │  输入即预览：面板内 240×96 实时小图
      ▼
③ 回车 / 点「插入图形 ⏎」
      │  画布生成 MathPlot 元素（短暂「出图中」过渡，实际解析 <100ms）
      │  自动选中 + 自动切回选择工具
      ▼
④ 元素即图形：可拖拽移动、8 控点缩放、属性面板实时调参
      │  定义域 / 采样精度 / 坐标系显隐 / 颜色 / 线宽 / 不透明度 / 方程标签
      ▼
⑤ 全部操作可 Ctrl+Z 撤销 / Ctrl+Shift+Z 重做；Del 删除；面板内可复制
```

**与 PRD 开放问题的对齐**：
- **OQ-1（选中即出图语义）**：原型采用 PRD 推荐方案——「元素即图形、创建即出图」，输入确认后直接生成元素并自动选中，无"选中文本再出图"的中间态。
- **OQ-2（坐标系策略）**：原型采用「元素自带局部坐标系」——每个 MathPlot 元素内含坐标轴 / 刻度 / 轻网格，随元素整体移动缩放，与背景点阵解耦；几何图形（圆 / 椭圆）自动等比 1:1 保证不失真。

## 5. MathPlot 元素参数清单（属性面板）

- **方程**：可编辑，回车/失焦实时重绘；类型徽标（显式函数 / 圆 / 椭圆 / 解析失败）
- **定义域** x∈[xmin, xmax]：数字输入 + 预设快捷（-2π~2π / -5~5 / -10~10，默认 -10~10）；仅显式函数
- **采样精度**：粗 160 / 中 320（默认）/ 细 640 采样点
- **坐标系**：坐标轴 / 刻度 / 网格显隐；等比 1:1（几何方程强制开启且隐藏该项）
- **线条颜色**：12 色板 + 自定义取色器；**线宽** 1–8px；**不透明度** 20–100%
- **方程标签**：元素左下角 chip 显示美化后的方程（x²、π 等Unicode 呈现）
- **操作**：复制（+26px 偏移）、删除（可撤销）

## 6. 支持的方程语法（原型内置解析器）

- 显式函数 `y=f(x)`（`y=` 可省略）：四则、`^` 幂、括号、隐式乘法（`2x`、`2sin(2x+π/3)`、`2πx`）
- 函数：sin cos tan sqrt abs ln log exp asin acos atan；常量 π、e；Unicode 直接支持：`² ³ ⁴ ˣ √ ·`
- 几何方程（参数化精确绘制，自动等比）：圆 `(x-a)²+(y-b)²=r²`、椭圆 `x²/A+y²/B=1`
- 间断处理：tan / 1/x 等自动断笔，不会画出贯穿渐近线的竖线
- 错误提示（不白屏不崩溃）：无法识别的符号 / 括号未闭合 / 表达式不完整 / 定义域内无有效值 / 暂不支持隐式方程（除圆/椭圆）

> 原型解析器为演示用安全实现（递归下降语法分析，无 eval）；生产选型（PRD 建议 MathLive + mathjs）由 ZOO-131 技术方案决定，交互行为不变。

## 7. 设计决策记录（供评审确认）

1. **插入后自动切回选择工具**：确认插入后立即选中元素并切回 V，属性面板即时显示参数便于微调；按 F 随时回到编辑器输入下一个方程。
2. **方程编辑器面板加宽**：默认属性面板 192px 放不下预览与模板，方程态加宽至 264px（同为浮动白底毛玻璃样式，视觉语言不变）。
3. **元素半透明白底**（88% 不透明度）：在点阵背景上保证坐标系可读，同时隐约透出网格保持白板感。
4. **错误占位也是元素**：非法方程生成红色占位元素（可移动/删除/撤销），点击原位修复——比"弹窗报错"更符合白板心智，也与 PRD §5.3-5 一致。
5. **「出图中」为短暂过渡态**（约 0.6s 动画）：实际解析在本地 <100ms，保留该态是为覆盖弱网/复杂表达式场景的视觉预期；评审演示面板可冻结查看。

## 8. 原型边界（未覆盖，属现有功能或后续迭代）

- 画笔 / 形状 / 文本 / 橡皮等现有工具为视觉占位（点击有提示），不在本原型范围
- 视口平移缩放、持久化 / 导出 / 缩略图为现有链路，原型仅保留顶栏入口
- 手写识别（PRD 定为远期）、隐式方程通用绘制（P2）未包含
