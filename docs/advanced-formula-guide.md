# 高级公式面板使用指南：四分区关系与组合用法

- 适用版本：`main` @ `49effbe`（ZOO-187 六阶段 T0–T6 全部合入）
- 面板入口组件：`src/components/math/AdvancedFormulaPanel.tsx`
- 本文是**使用文档**：讲清「微积分 / 物理模板 / 常量 / 参数式」四个分区各自是什么、彼此什么关系、什么时候组合用、怎么组合。所有截图来自真实应用实测（dev server + 浏览器逐步操作），配图见 Multica 任务 ZOO-204 交付评论附件（本仓库文本版不带图，图号与评论附件一一对应）。

## 0. 面板怎么打开（两个入口）

**入口 1（创建侧）**：工具栏选 `ƒ` 数学图形工具 → 点击画布 → 方程编辑器模板分组底部有一行虚线框按钮「∫ 微积分 / 物理公式…」→ 点击弹出「高级公式」二级面板。（图 1）

**入口 2（编辑侧）**：选中画布上的数学图形 → 右侧属性面板出现「⚙ 公式设置」按钮（带已开启叠加数徽标）→ 点击弹出同一面板。（图 4 属性面板可见该按钮）

> 「公式设置」按钮**只对高级元素出现**：绑定了常量、开启了叠加、或方程是参数式 / 极坐标。普通方程（如 `y=sin(x)`）不出现任何新控件——要给普通方程加微积分叠加，走入口 1 在创建时勾选。

关闭面板：点击背板 / 按 `Esc` / 点标题栏 `×`，三路同源；开合是纯界面状态，不进入撤销历史。

面板内四个分区按固定顺序排列：**微积分 → 物理模板 → 常量 → 参数式**（图 2）。

## 1. 四分区各自是什么

| 分区 | 字形 | 一句话定位 | 区内控件 |
|---|---|---|---|
| 常量 | `A` | 给方程里的符号常量（g、v₀、θ、ω、A、φ…）赋值的**字典**——其他三个区的「带参数公式」都靠它出图 | 预置槽 6 个 + 已绑定值编辑 + 自定义项 + 解析状态行 + 示例模板 `y=A·sin(ωx+φ)` |
| 微积分 | `∫` | **显式函数 y=f(x) 专属**的叠加分析层 | f′ 导函数虚线开关、切线演示开关（+ 切点 x₀）、定积分着色开关（+ 区间 a/b）、×10 邻域放大（中心 + 按钮，仅编辑侧） |
| 物理模板 | `⚛` | **整包物理模板**：点选即回填「方程 + 常量预置 + t 域预置 + 标注预置」全套 | 抛体运动 / 简谐振动 / 匀速圆周运动 3 个模板 + R·H 落地/峰值标注开关 + 常量单位显示行 |
| 参数式 | `t` | **参数方程与极坐标方程的输入域**：x=f(t),y=g(t) 与 r=f(θ) | 参数圆 / 心形线 / 摆线 / 李萨如 4 个模板 + t/θ 取值范围输入 |

各区补充说明：

- **常量区**：预置槽点一次添加（缺省值 g=9.8、v₀=1、θ=π/4、ω=1、A=1、φ=0），再点一次移除；绑定行数值输入实时预览、失焦记一条撤销。自定义符号支持书写原貌（θ、λ…），需字母开头、≤8 字符、仅字母数字，x/y/e/π 为保留名；数值容忍单位后缀（`9.8 m/s²` → 9.8，单位仅显示不参与运算）。底部解析状态行实时反馈：合法显式函数报「✓ 已识别：显式函数 y=f(x)」，欠定（有符号没赋值）则红字引导补常量。（图 3）
- **微积分区**：只在方程被识别为显式函数时可用；否则控件整体禁用并提示「仅显式函数 y=f(x) 支持微积分叠加」，**已配置的叠加数据保留**，方程改回显式即自动恢复生效。×10 邻域放大只在编辑侧渲染（创建时元素尚无定义域）。
- **物理区**：模板点选是「整包回填」——抛体模板会同时回填方程 `x=v₀·cos(θ)·t,y=v₀·sin(θ)·t-0.5·g·t²`、常量 {v₀=20, θ=π/6, g=9.8}、t 域 [0, 2.04]（落地时间）、勾选 R·H 标注，插入即出图（图 10）。单位行（如 `v₀ = 20 m/s · θ = 0.5236 rad · g = 9.8 m/s²`）只做显示。
- **参数式区**：方程是参数式 / 极坐标时 t/θ 范围输入激活（直改实时预览）；否则禁用并提示，但模板行仍可点选引导。

## 2. 关系与组合矩阵（本指南的骨架）

| 组合 | 关系 | 说明 |
|---|---|---|
| 常量 × 任何区 | ✅ **可组合（地基）** | 常量是全局字典：显式函数、参数式、极坐标里的符号常量都由它裁决。没有它，`y=A·sin(ωx+φ)` 是欠定方程，无法出图 |
| 微积分 × 常量 | ✅ **常用组合** | `y=A·sin(ωx+φ)` 绑常量后开 f′，导函数随常量改值**实时重算**（例 1） |
| 物理模板 × 常量改值 | ✅ **核心玩法** | 抛体改 g/θ/v₀，轨迹与 H/R 标注**实时联动**（例 2） |
| 参数式 × 常量 | ✅ **物理价值的来源** | `x=v₀·cos(θ)·t` 配常量绑定就是抛体——物理模板本质是「参数式 + 常量 + 域 + 标注」的预制包 |
| 邻域放大 × 微积分叠加 | ✅ **教学连招** | tan 的渐近行为 + f′ 同屏演示（例 5） |
| 定积分 × 常量 × 定义域 | ✅ **组合** | 积分区间 a/b 需在定义域内；被积函数先代入常量（例 4） |
| 微积分 × 参数式 / 极坐标 / 几何 | ⛔ **互斥** | 叠加仅对显式函数生效：控件禁用但**数据保留**，方程改回显式即恢复（图 15） |
| 物理标注（R·H）× 显式函数 | ⛔ **互斥** | 标注仅对参数式轨迹 x=f(t),y=g(t) 生效；简谐振动（x(t)=… 形态，识别为显式函数）走常规曲线渲染，标注禁用（图 13） |

两条互斥口径的实现依据（`AdvancedFormulaPanel.tsx`）：微积分区 `applicable = (kind === 'explicit')`；物理区标注 `applicable = (kind === 'parametric')`。两区的叠加条目存于同一个 overlays 数组、互不覆盖——你可以同时勾着 f′ 和 R·H，各自只在自己的生效面上渲染，切到另一面自动让位。

## 3. 六个实操例子（全部真实应用实测）

### 例 1：常量 + 微积分——导函数随 ω 实时变

**一句话点破：f′ 是对「代入常量后」的函数求导**——面板先解出 y=sin(2x)，再对它求导，所以图例显示的是 `y′=2·cos(2·x)` 而不是带符号的形式。

步骤：

1. `ƒ` 工具 → 点画布 → 面板底部「∫ 微积分 / 物理公式…」打开高级面板；
2. 常量区点模板「正弦参数式」回填 `y=A·sin(ωx+φ)`；
3. 点预置槽 `A`、`ω`、`φ` 三个槽（缺省 A=1、ω=1、φ=0），把 ω 的值改为 **2**；解析状态行显示「✓ 已识别：显式函数 y=f(x)」（图 3）；
4. 关闭面板 → 「插入图形」出图（图 4）；
5. 选中图形 → 「⚙ 公式设置」→ 微积分区勾选 **f′(x) 导函数虚线叠加**：实线主曲线 + 绿色虚线导函数，图例 `y=A·sin(ωx+φ)` 与 `y′=2·cos(2·x)`（图 5）；
6. 常量区把 ω 从 2 改成 **3**：主曲线与导函数**同步**变密，图例实时变为 `y′=3·cos(3·x)`（图 6）。

预期结果对照：ω=2 时导函数振幅 A·ω=2、周期 π；ω=3 时振幅 3、周期 2π/3——「频率跟着 ω 走、振幅跟着 A·ω 走」一目了然。

### 例 2：物理模板核心玩法——抛体改 g，轨迹与 H/R 联动

1. 新建方程 → 高级面板 → 物理区点「抛体运动」模板：方程 / 常量 {v₀=20, θ=π/6≈0.5236, g=9.8} / t 域 [0, 2.0408] / R·H 标注**整包回填**，单位行显示 `v₀ = 20 m/s · θ = 0.5236 rad · g = 9.8 m/s²`（图 10；此时微积分区禁用——方程是参数式，互斥口径可见）；
2. 「插入图形」：抛物线轨迹 + 峰值点、落地点标记与虚线导引，标注 **H = 5.1、R = 35.35**（图 11）；
3. 「⚙ 公式设置」→ 常量区把 g 从 9.8 改成 **25**：轨迹当场变矮变短，标注实时变为 **H = 2、R = 13.86**（图 12）。

手算对照（g=25）：H = (v₀sinθ)²/2g = 100/50 = **2** ✓；R = v₀²·sin2θ/g = 400×0.866/25 = **13.86** ✓。改 θ（出射角）或 v₀（初速）同理联动——课堂上一节课能扫完整张抛体参数表。

### 例 3：简谐振动——改 A 看振幅

1. 新建方程 → 高级面板 → 物理区点「简谐振动」模板：回填 `x(t)=A·cos(ωt+φ)` + 常量 {A=2, ω=1, φ=0} → 插入（图 13）；
2. 「⚙ 公式设置」→ 常量区把 A 从 2 改成 **4**：振幅当场翻倍（波峰 2→4、波谷 −2→−4），周期不变（ω 没动）（图 14）。

两个口径说明：① 简谐的 `x(t)=…` 形态被识别为**显式函数**（自变量 t），所以 R·H 标注禁用（标注仅对参数式轨迹生效，面板有文字提示）；② 也因此模板的 t 域预置 [0, 4π] 不落地——插入后 t 域取缺省 [−10, 10]，需要收窄时在属性面板「定义域 t ∈」或参数式分区改。改 ω 看周期、改 φ 看初相，都在常量区一步完成。

### 例 4：定积分 + 常量 + 定义域——面积 chip 与手算对照

1. 沿用例 1 的 `y=A·sin(ωx+φ)`（A=1、ω=2、φ=0，即 y=sin(2x)）；
2. 「⚙ 公式设置」→ 微积分区勾选 **∫ 定积分着色**，区间填 **a=0、b=1.5708**（= π/ω = π/2）；
3. 曲线下方出现半透明着色区域，图例给出面积 chip（图 12）。

手算对照：∫₀^{π/2} sin(2x)dx = [−cos(2x)/2]₀^{π/2} = (1+1)/2 = **1**，chip 显示 **= 1** ✓。通用公式：φ=0 时 ∫₀^{π/ω} A·sin(ωx)dx = 2A/ω——改 A 或 ω，着色区域与数值实时跟着变，正好用来讲「面积对参数的依赖」。

> a/b 校验：必须 a<b 且落在定义域内，否则红字提示；区间内有无定义点由渲染层奇点防护兜底（画报错 chip 而不是产出错误区域）。

### 例 5：邻域放大连招——tan 渐近行为 + f′

1. 新建方程 `y=tan(x)` → 高级面板（入口 1）→ 微积分区勾选 **f′**（创建侧先起草叠加；注意邻域放大控件此时不渲染——元素还没建立，无定义域可改）→ 插入：全定义域 tan 主曲线 + U 形虚线导函数 `y′=1/cos(x)²`，渐近线处两支自然断开、无伪竖线（图 13）；
2. 选中图形 → 「⚙ 公式设置」→ 微积分区底部「邻域放大」中心填 **1.5708**（≈π/2）→ 连点两次 **×10**：定义域 [-10,10] → [1.4708, 1.6708]（宽 20 → 2 → 0.2），视野聚焦到渐近线两侧（图 14）。

预期结果：tan 两支在渐近线两侧断开上扬、中间干净无伪竖线；f′ 的两个 U 形碗在中心处趋向 +∞——「极限行为」不用擦黑板，连点两次就到。

> ×10 的口径：以中心（缺省取当前域中心）收窄 10 倍，边界整体钳制回当前域内；连点幂等，最窄到 0.1（采样层下限）不再收。

### 例 6：参数式 / 极坐标独立线——心形线与 θ 域调整

1. 新建方程 → 高级面板 → 参数式区点「心形线」回填 `r=1+cos(θ)`：解析状态「✓ 已识别：极坐标方程 r=f(θ)」，θ 范围输入激活（0 ~ 6.2832）。**此时微积分区禁用**（提示「仅显式函数…」）、物理区 R·H 也禁用（仅参数式轨迹）——这就是两条互斥口径的实拍（图 15）；
2. 插入：完整心形，尖端朝右（图 16）；
3. 「⚙ 公式设置」→ 参数式分区把 θ 上限从 6.2832 改成 **3.1416**（π）：只剩上半颗心（θ∈[0,π] 画出上支弧），属性面板定义域同步显示 θ ∈ 0~3.1416（图 17）。

为什么微积分此时禁用：f′、切线、定积分都定义在 y=f(x) 上；极坐标 / 参数式曲线没有全局的「y 对 x」函数关系，叠加层无从挂载。想分析心形线的性质，用 θ 域截段 + 常量构造族（如 `r=a+cos(θ)` 绑常量 a）来教学。

## 4. 一图流决策指引：我想……该用哪个区

| 我想画 / 分析 | 用哪个区 | 要不要组合 |
|---|---|---|
| 画抛物线轨迹并标射程 R / 峰高 H | 物理区 · 抛体运动 | 插入即出图；改 g/θ/v₀ 联动是核心玩法 |
| 讲简谐振动（振幅 / 周期 / 初相） | 物理区 · 简谐振动 | 常量区改 A/ω/φ 实时变 |
| 画圆 / 心形线 / 摆线 / 李萨如 | 参数式区模板 | 需要时配常量（如 r=a+cos(θ)） |
| 任意带符号参数的显式曲线 | 方程输入 + **常量区**（地基） | 后续任何分析都建立在常量绑定上 |
| 讲导数 / 切线 | 微积分区 f′ / 切线 | 配常量区：导函数随参数实时变 |
| 讲定积分面积 | 微积分区 ∫ a/b | 配常量 + 注意 a/b 在定义域内 |
| 讲极限 / 渐近行为（tan、1/x） | 微积分区 ×10 邻域放大 | 编辑侧操作；配 f′ 同屏讲变化率 |
| 极坐标曲线 r=f(θ) | 参数式区 | 微积分互斥（仅显式生效），用 θ 域截段代替 |

## 5. 细节与口径（附录）

- **常量键的存储与显示**：存储层一律 ASCII 名（theta / omega / v0 / a…），显示层还原原貌（θ / ω / v₀）；A 没有专属映射，绑定行显示为小写 `a`。
- **改值的历史口径（D5）**：数值输入 onChange 实时预览（直改不进历史），onBlur / 离散点击（开关、模板、预置槽、×10）提交**一条**撤销记录——连续调参不会刷屏撤销栈。
- **互斥 ≠ 丢弃**：切换方程形态时，不适用的叠加只是禁用挂起，数据保留在元素上；方程改回生效形态自动恢复。overlays 数组由微积分区与物理区共用，各自过滤自己的条目类型，互不覆盖。
- **「公式设置」显隐口径**：元素带 overlays（非空）/ constants（非空）/ 参数式·极坐标 kind 才出现；清空常量与叠加后元素回到普通表现。
- **两入口差异**：创建侧（方程编辑器）所有分区编辑的是草稿，确认插入时随载荷全量带出；邻域放大只在编辑侧渲染（创建时无元素定义域）。编辑侧直连元素字段，实时重绘。
- **单位仅显示**：常量值恒以纯数存储与运算，`m/s²` 等单位字符串只出现在显示层，不做量纲运算；R/H 标注不带单位（量纲取决于用户的单位制）。
