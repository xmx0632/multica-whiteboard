## 1. 背景

教学白板（迭代一·单机版）已具备常规白板可用形态：自由画笔、矩形/圆/直线/箭头/文本/橡皮、选择移动缩放、撤销重做、本地持久化与缩略图。技术栈 Next.js 16 + React 19 + TypeScript + Tailwind v4 + Zustand。

本次要交付的**核心差异化能力**是：**在白板上输入数学方程，自动渲染对应矢量图形（如 sin 曲线、二次函数、圆等），并作为可编辑的白板元素存在。**

## 2. 目标

- 让教师在课堂上"**输入方程 → 秒出可编辑矢量图**"，覆盖中学到大学基础数学常用函数族与几何方程。
- 图形是**矢量白板元素**：可选中、移动、缩放、改样式、撤销重做、持久化，与现有元素无差别共存。
- 不回归任何现有白板功能。

**非目标（本期不做）**：实时多人协同、云端多端同步、多页/多画布管理（见 §7）。

## 3. 目标用户与典型场景

**主用户**
- 中学/高校数学教师（课堂演示、板书生成）
- 学生（自学、作业验证、函数图像直观理解）

**典型场景**
1. 讲三角函数图像变换：输入 `y=sin(x)`、`y=2sin(2x+π/3)`，对比振幅/周期/相位。
2. 讲二次函数：输入 `y=x²-2x-3`，直观看顶点、与 x 轴交点。
3. 讲圆锥曲线：输入圆 `(x-1)²+(y-2)²=9`、椭圆 `x²/9+y²/4=1`。
4. 讲指数/对数：输入 `y=2ˣ`、`y=ln(x)`，观察单调与定义域。
5. 课堂对比：同屏多个函数图像，配合画笔批注关键点。

## 4. 用户故事

- **US-1**：作为教师，我想选择"方程"工具直接输入 `y=sin(x)`，确认后画布上立刻出现带坐标系的 sin 曲线，便于课堂演示。
- **US-2**：作为教师，我想选中某条曲线后，在属性面板调整定义域（如只看 `x∈[-2π,2π]`）、线条颜色与粗细，曲线实时变化。
- **US-3**：作为教师，我想从模板一键插入"二次函数/圆方程"骨架再微调，降低输入门槛。
- **US-4**：作为教师，我想把生成的曲线像普通图形一样移动、缩放、复制，与我的板书排版共存。
- **US-5**：作为教师，当我输入了无法识别的方程时，我要看到清晰的错误提示，而不是白屏或崩溃。
- **US-6**：作为教师，我想保存白板后重新打开，曲线和参数都还在。

## 5. 核心功能定义

### 5.1 方程输入方式（含推荐）

候选三种：手写识别 / 文本公式编辑器 / 模板插入。

| 方式 | 体验 | 准确率/可控性 | 离线 | 成本/风险 | 结论 |
|---|---|---|---|---|---|
| 文本公式编辑器（所见即所得，如 MathLive） | 键盘高效、实时预览、可二次编辑 | 高、确定性强 | ✅ 纯前端 | 低 | **MVP 主输入** |
| 模板插入（常见方程骨架库） | 一键上手、零门槛 | 高 | ✅ | 低 | **MVP 辅助输入** |
| 手写识别（OCR/笔画识别） | 炫、移动/触屏友好 | 受字形/连笔影响，教学大屏不刚需 | 需本地模型，体积大 | 高（准确率、延迟、体积） | **远期 P2/未来** |

**推荐方案**：**以"文本公式编辑器为主 + 模板插入为辅"作为 MVP 输入；手写识别列入未来迭代，不进首期。**

理由：教学主场景为桌面/触屏一体机，键盘输入效率与可控性远高于手写识别；模板可覆盖新手与高频方程；手写识别的准确率、离线模型体积与延迟风险与 MVP"稳、快、离线"目标冲突。（编辑器库选型由技术方案 ZOO-131 决定，产品侧建议候选：输入用 MathLive，解析用 mathjs。**技术方案最终选型为自研受控文本框 + mathjs，见 `docs/design/mathplot-technical-design.md` D1/D2。**）

### 5.2 支持的方程类型与优先级

按"显式函数 `y=f(x)` 优先、隐式/参数/极坐标后置"的原则分期（显式函数采样绘制简单可控，隐式需数值算法，风险与成本显著更高）。

| 优先级 | 方程类型 | 示例 |
|---|---|---|
| **P0（MVP 必做）** | 一次函数 | `y=2x+1` |
| | 二次/多项式（n≤4） | `y=x²-2x-3`、`y=x³-2x` |
| | 三角函数（含系数/相位） | `y=sin(x)`、`y=2sin(2x+π/3)`、`tan(x)` |
| | 幂/根/反比例 | `y=√x`、`y=1/x`、`y=x³` |
| **P1（紧随 MVP）** | 指数/对数 | `y=2ˣ`、`y=eˣ`、`y=ln(x)` |
| | 绝对值/分段 | `y=|x-1|` |
| | 圆（隐式） | `(x-1)²+(y-2)²=9` |
| | 椭圆（隐式） | `x²/9+y²/4=1` |
| **P2（后续迭代）** | 抛物线/双曲线等圆锥曲线全集 | `x²=2py`、`x²-y²=1` |
| | 参数方程 / 极坐标 | `r=2cos(θ)` |
| | 隐式方程 `f(x,y)=0` 通用数值绘制 | `sin(x·y)=0` |
| | 不等式区域、关键点标注（零点/顶点/交点） | — |

### 5.3 "选中方程 → 自动出图"交互定义

**核心产品决策（已评审采纳，见 §12 OQ-1）**：引入独立的**"数学图形元素（MathPlot）"**——一个自带局部坐标系 + 方程曲线的复合元素。**创建即出图**：用户输入方程并确认后，直接在画布生成 MathPlot 元素（图形立即可见）并自动选中；这正是"写出方程 → 自动出图"的产品语义，无需额外的"选中才出图"动作。选中后可在属性面板编辑方程与参数、实时重绘。

> 说明：项目目标原文为"写出方程式，**选中后**自动显示图形"。PRD 将其细化为"元素即图形、创建即出图"，避免"选中文本→临时叠加图形→取消选中消失"带来的状态闪烁与语义混乱；同时保留"选中文本→一键转换为图形"作为 P1 增强能力。交互细节以 `docs/prototype/interaction-spec.md` 为基线。

**交互流程**
1. 左侧工具栏选 **Equation**（快捷键 `F`）→ 右侧属性面板切换为方程编辑态（输入框 + 实时预览 + 模板入口）。
2. 输入方程 → 实时预览曲线；点确认（或回车）→ 在画布生成 MathPlot 元素，自动选中，并切回选择工具。
3. 选中元素 → 属性面板显示：方程文本、定义域、采样精度、坐标轴/网格显隐、线条颜色/线宽、x/y 单位比例。
4. 修改任一参数 → 实时重绘。
5. 无法识别/无界 → 元素呈"错误态"（红色占位框 + 错误提示），可点击重新编辑方程。

**坐标系与网格策略（已评审采纳，见 §12 OQ-2）**
- 白板现有背景为**点阵网格（dot grid）**，并非笛卡尔坐标系。因此 MathPlot 元素**自带局部坐标系**：原点、x/y 单位、坐标轴、刻度、轻量网格作为元素的可选叠加层（默认显示坐标轴 + 轻网格）。
- 局部坐标系随元素一起移动/缩放，不与全局视口耦合；背景点阵仅作绘图参考。

**可调参数**
- 定义域 `[xmin, xmax]`（默认 `[-10, 10]`，可滑块/输入）
- 采样精度（步长，随视口缩放自适应以兼顾性能与平滑度）
- 坐标轴 / 刻度 / 网格 显隐
- 线条颜色、线宽、不透明度（复用现有 stroke 体系）
- x/y 单位比例（控制纵横比）
-（P2）关键点标注：零点、顶点、与坐标轴交点

## 7. 常规白板能力差距评估与 MVP 边界

**现状盘点**
- ✅ 已有：自由画笔、矩形/圆/直线/箭头/文本、选择/移动/缩放、撤销重做、本地持久化、缩略图、视口平移缩放。
- ❌ 缺失：多页/多画布、图片插入、导出（PNG/PDF）、图形编组/对齐、富文本、云端同步/多端、实时协同、分享/权限。

**MVP 边界决策**

| 能力 | 本期(方程出图 MVP) | 说明 |
|---|---|---|
| 方程输入 + 自动出图（P0 方程族） | ✅ 纳入 | 核心差异化，必须做 |
| 图形作为元素（选中/移动/缩放/撤销重做/持久化） | ✅ 纳入 | 验收硬指标 |
| 导出 PNG/PDF | ⏳ P1 快速跟进 | 教学刚需（保存板书），建议主链路稳定后单开小迭代 |
| 图片插入 | ⏳ P1 快速跟进 | 插入题目图片是高频场景，成本低收益高 |
| 多页/多画布 | ❌ 不纳入 | 独立大模块，会稀释焦点 |
| 云同步/多端/实时协同/分享权限 | ❌ 不纳入 | 架构级改造，需独立立项 |

**结论**：本期聚焦"方程出图"差异化，不纳入协同/云/多页；但强烈建议把"导出 PNG/PDF"与"图片插入"作为**P1 紧随**（教学刚需、成本可控），在方程出图主链路验证后插入一个小迭代。

## 8. 非功能需求

- **性能**：单曲线采样点数受控（建议 ≤ 2000），缩放/平移保持 60fps；同屏 ≤ 20 个图形流畅；采样步长随视口缩放自适应。隐式/参数方程（P2）需评估数值绘制性能后再定阈值。
- **离线**：纯前端，解析与渲染全部本地完成，不依赖任何外部 API；若未来引入手写识别须提供本地模型或优雅降级。
- **跨端**：优先桌面浏览器 + 教学触屏一体机（大屏）；移动端保证只读与基本可用，不强求精细编辑；工具栏响应式。
- **安全**：方程解析必须沙箱化，**禁止 `eval`**，采用 mathjs 等安全解析器，杜绝公式注入。
- **可访问性**：方程输入键盘可达、支持快捷键、控件对比度达标。
- **稳健性**：非法/无界/除零等输入不得导致白屏或崩溃，统一以"错误态 + 提示"承接。

## 10. 验收标准

1. 选择 Equation 工具输入 `y=sin(x)`，确认后画布出现带坐标系与网格的 sin 曲线矢量元素，并自动选中。
2. §5.2 中 **P0** 全部方程类型可正确出图（一次/二次/多项式/三角/幂根/反比例）。
3. 选中图形可在属性面板调整定义域、采样、轴显隐、颜色、线宽，修改后实时重绘。
4. 图形可选中、移动、缩放；删除可撤销/重做；保存后重开图形与参数仍在。
5. 输入非法/无界方程时显示明确错误提示，不白屏、不崩溃。
6. 现有白板工具（画笔/形状/文本/选择/橡皮等）**零回归**。
